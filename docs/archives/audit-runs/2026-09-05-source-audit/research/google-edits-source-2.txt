Page Summary
outlined_flag
This documentation describes how to update a track using a PUT request to the specified URL.
The request requires path parameters for the package name, edit ID, and track identifier.
The request body should contain an instance of Track, and a successful response will also contain an instance of Track.
Authorization requires the https://www.googleapis.com/auth/androidpublisher OAuth scope.
HTTP request
Path parameters
Request body
Response body
Authorization scopes
Try it!
Updates a track.
HTTP request
PUT https://androidpublisher.googleapis.com/androidpublisher/v3/applications/{packageName}/edits/{editId}/tracks/{track}
The URL uses gRPC Transcoding syntax.
Path parameters
Parameters
packageName
string
Package name of the app.
editId
string
Identifier of the edit.
track
string
Identifier of the track.
More on track name
Request body
The request body contains an instance of Track.
Response body
If successful, the response body contains an instance of Track.
Authorization scopes
Requires the following OAuth scope:
https://www.googleapis.com/auth/androidpublisher
